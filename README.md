# EMS Project

This repository contains two subprojects:

- `ems-backend` — Spring Boot (Maven) backend.
- `ems-frontend` — React frontend.

Quick start

Backend (from `ems-backend`):

```bash
./mvnw spring-boot:run
# or if using installed Maven
mvn spring-boot:run
```

Frontend (from `ems-frontend`):

```bash
npm install
npm start
```

Environment variables

Create `.env` (or other `.env.*`) files locally for secret or environment-specific values — these are ignored by Git.
